# PROGRESS — журнал работ Soma Amp

## 2026-10-15 — Старт проекта
**Что сделал:** создал папку проекта, правила (`CLAUDE.md`), план (`ROADMAP.md`), инструкцию запуска (`START.md`). В `ui/` положил копию веб-плеера с deemmoor.ru/soma: `index.html` и иконки. Фото-фон не взял: в приложении окна плеера лежат прямо на рабочем столе, как у Winamp.
**Зачем:** решили делать десктопную версию на Rust + Tauri 2. Интерфейс берём готовый, а Rust добавляет то, что браузер не умеет: трей, глобальные медиаклавиши, выключение ПК по таймеру сна, окно без рамки.
**Файлы:** `CLAUDE.md`, `ROADMAP.md`, `START.md`, `ui/`.
**Как посмотреть:** открыть `ui/index.html` в браузере — это текущий плеер.
**Новые слова:** Tauri — фреймворк, который показывает HTML-интерфейс в окне системного WebView (на Windows это Edge) и даёт ему вызывать функции, написанные на Rust.
**Дальше:** 0.1 — проверка окружения.

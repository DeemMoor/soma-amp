## 2026-10-15 — 1.1 Каркас Tauri
**Что сделал:** командой `cargo tauri init` создал папку `src-tauri/` — это Rust-часть приложения. Интерфейс берётся прямо из `ui/` (`frontendDist: "../ui"`), без dev-сервера. Окно 480×900 с заголовком «Soma Amp». Иконки для `.exe` и установщика сгенерил из `ui/icon-512.png` командой `cargo tauri icon` (мобильные `android/` и `ios/` удалил — мы только под десктоп). Подчистил то, что init добавил по шаблону: команды `npm run dev/build` (npm у нас нет), плагин `tauri-plugin-log` и крейт `log` (не согласованы в роадмэпе), имена-заглушки `app` и `com.tauri.dev` → `soma-amp` и `ru.deemmoor.somaamp`.
**Зачем:** это минимальный скелет: Rust открывает окно WebView и показывает в нём наш готовый плеер. Всё остальное будем наращивать на нём.
**Файлы:** `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml`, `src-tauri/src/main.rs`, `src-tauri/src/lib.rs`, `src-tauri/capabilities/default.json`, `src-tauri/icons/`.
**Как посмотреть:** в `C:\projects\soma-amp`: `cargo tauri dev`. Первая сборка долгая (несколько минут), дальше быстрее. Пока в окне видна системная рамка, фото-фон и карточка «Установить» — их уберём в пунктах 1.3, 2.1, 2.2.
**Новые слова:**
- `Cargo.toml` — паспорт Rust-проекта: имя, версия и список зависимостей (крейтов).
- `Cargo.lock` — точные версии всех скачанных крейтов; храним в git, чтобы сборка завтра была такой же, как сегодня.
- `main.rs` и `lib.rs` — `main.rs` только вызывает `run()` из `lib.rs`; вся логика живёт в библиотеке, так её проще тестировать.
- `tauri::Builder` — «конструктор» приложения: цепочкой вызовов подключаем плагины и команды, в конце `.run(...)` запускает окно.
- `#[cfg_attr(...)]`, `#![...]` — атрибуты: подсказки компилятору. Например, `windows_subsystem = "windows"` в релизе не показывает чёрное окно консоли.
- `.expect("...")` — «если тут ошибка, упади с этим сообщением». В рабочем коде так не делаем (там `?`), но в самом корне запуска это норма: без окна приложению делать нечего.
- `capabilities/` — список того, что JS в окне имеет право вызывать в Rust. Пока только базовое `core:default`.

## 2026-10-15 — 1.3 Прячем в приложении то, что нужно только сайту
**Что сделал:** в начале `ui/index.html` завёл флаг `IS_DESKTOP = !!window.__TAURI__`. В приложении он `true`: на `<html>` вешается класс `desktop`, и CSS прячет фото-фон `.bg` и подпись `.credit`; карточка «Установить» и пункт меню «Установить как приложение» не показываются; service worker не регистрируется; `<link rel="manifest">` теперь добавляется скриптом только на сайте. Чтобы `window.__TAURI__` вообще появился, включил в `tauri.conf.json` `"withGlobalTauri": true`.
**Зачем:** приложению не нужна установка как PWA, а фон по плану будет прозрачным. Через флаг, а не удалением кусков, — чтобы файл можно было без правок положить обратно на сайт: там всё работает как раньше.
**Файлы:** `ui/index.html`, `src-tauri/tauri.conf.json`.
**Как посмотреть:** `cargo tauri dev` — фото, подписи и карточки нет. Открыть `ui/index.html` с сайта — всё на месте.
**Новые слова:** `withGlobalTauri` — настройка Tauri, которая кладёт в окно объект `window.__TAURI__` с функциями для связи с Rust. Нам он нужен, потому что у нас нет сборщика (npm/Vite), через который обычно подключают JS-библиотеку Tauri.
**Перенести на сайт:** флаг `IS_DESKTOP` и манифест через скрипт — сайту безвредно, можно перенести, чтобы файлы не расходились.

## 2026-10-15 — 2.1 Окно без системной рамки
**Что сделал:** в `tauri.conf.json` поставил `"decorations": false` — рамка и заголовок Windows исчезли. Окно двигается мышью за любой заголовок плеера (`.tb`: SOMA AMP, EQUALIZER, PLAYLIST EDITOR). В заголовок главного окна добавил кнопки `−` (свернуть) и `×` (закрыть), они видны только в приложении (класс `desk-only`). В `capabilities/default.json` выдал окну три права: перетаскивание, свернуть, закрыть.
**Зачем:** как у Winamp — плеер сам себе рамка. Вместо атрибута `data-tauri-drag-region` из плана написал короткий обработчик `mousedown` → `startDragging()`: у атрибута двойной клик разворачивает окно на весь экран, а у нас двойной клик по заголовку уже занят shade-режимом. Тащим только по одиночному клику (`e.detail === 1`) и не по кнопкам.
**Файлы:** `src-tauri/tauri.conf.json`, `src-tauri/capabilities/default.json`, `ui/index.html`.
**Как посмотреть:** `cargo tauri dev` → потянуть за заголовок, нажать `−`, вернуть из панели задач, двойной клик по заголовку → shade.
**Новые слова:** capabilities (права) — в Tauri 2 JS в окне по умолчанию почти ничего не может сделать с окном и системой; каждое действие (`core:window:allow-minimize` и т.п.) надо явно разрешить в файле из `capabilities/`. Так случайный или чужой скрипт на странице не получит лишней власти.
**Дальше:** 2.2 — прозрачное окно.

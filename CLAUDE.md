# CLAUDE.md — правила работы над Soma Amp (десктоп)

> Читается Claude Code автоматически при старте. Это «договор»: как работать,
> что можно, чего нельзя. Если правило мешает сиюминутной просьбе — спроси.

## Что это

- **Soma Amp** — десктопный плеер радио SomaFM в стиле Winamp 5 Modern.
- Основа — веб-плеер с сайта `https://deemmoor.ru/soma/` (исходник лежит в `ui/index.html`).
- Стек: **Rust + Tauri 2**. Интерфейс — наш готовый HTML/CSS/JS из `ui/`, без сборщиков
  (никаких Vite/React/npm, пока владелец не попросит). Rust отвечает за то, чего браузер не умеет.
- ОС разработки: **Windows**, терминал **PowerShell**. Пути — `C:\projects\soma-amp`.
- Владелец Rust **не знает** и учится по ходу. Объясняй как школьнику: каждое
  непустое решение — «почему так, а не иначе». Новые понятия Rust (владение,
  `Result`, `async`, макросы, крейты, команды Tauri) разбирай в `docs/PROGRESS.md` мини-уроком.

## Как работаем

1. Открой `docs/ROADMAP.md`, найди **первый невыполненный пункт** (`- [ ]`).
2. Сделай **только его**. Не убегай вперёд.
3. Проверки: `cargo fmt`, `cargo clippy -- -D warnings`, `cargo test` (в `src-tauri`),
   и запуск `cargo tauri dev`, чтобы глазами убедиться, что работает.
4. Один логический коммит в ветку `work` (не в `master`, **не пушить**).
5. Запись **в конец** `docs/PROGRESS.md` (формат ниже), отметка `- [x]` в `docs/ROADMAP.md`.
   Заметное для пользователя изменение — одна короткая строка в `CHANGELOG.md`, раздел «Не выпущено»
   («Улучшена безопасность», «Мелкие правки»; крупная фича — отдельной строкой, без подробностей).
6. Остановись и коротко подведи итог по-русски.

### Формат записи в docs/PROGRESS.md

```
## <дата> — <короткий заголовок>
**Что сделал:** простыми словами.
**Зачем:** почему так.
**Файлы:** главные файлы.
**Как посмотреть:** команды / что нажать.
**Новые слова:** новые понятия Rust/Tauri — по одному предложению.
**Дальше:** следующий пункт.
```

## ✅ Можно и нужно

- Идиоматичный Rust: `Result` и `?` вместо `unwrap()` в рабочем коде, `clippy` без предупреждений.
- Комментарии в коде — **по-русски**, имена — **только английские**.
- Тесты на логику (таймер сна, разбор битрейта, хранение настроек).
- Маленькие шаги, один коммит = одна мысль.
- Правки интерфейса делать в `ui/index.html`. Если правка полезна и сайту — записать
  в `docs/PROGRESS.md` пометку «перенести на сайт», но сайт **не трогать**.

## ⛔ Нельзя без явного «да» владельца

- **Не пушить**, не сливать в `master`, не публиковать релизы.
- **Не добавлять крейты/плагины**, кроме уже согласованных в `docs/ROADMAP.md`. Новый — сначала
  объясни зачем и какие альтернативы.
- **Не выдумывать фичи** вне `docs/ROADMAP.md`. Идею — в раздел «Идеи на потом».
- **Не выключать/не перезагружать компьютер** при тестах. Команду выключения тестировать
  только в «сухом» режиме (логируем, что бы выполнили), реальный вызов — только владелец руками.
- **Не трогать** файлы вне `C:\projects\soma-amp`, кроме чтения исходника сайта.
- **Не ставить** системный софт (Rust, Build Tools и т.п.) сам — только сказать владельцу, что поставить.
- **Не добавлять в коммиты трейлеры** `Co-Authored-By: Claude`, `Generated with` и любые подписи ИИ.

## Структура (после пункта 1 роадмэпа)

```
soma-amp/
  ui/                 — интерфейс плеера (HTML/CSS/JS, фон, иконки)
  src-tauri/
    src/main.rs       — точка входа
    src/lib.rs        — команды Tauri (то, что JS вызывает в Rust)
    tauri.conf.json   — настройки окна, иконки, сборки
    capabilities/     — какие права есть у окна (Tauri 2)
    Cargo.toml        — зависимости Rust
  docs/            — DEVELOPMENT.md (в git); START, ROADMAP, PROGRESS — личные, в .gitignore
  CLAUDE.md  README.md  CHANGELOG.md
```
